# Kinlin AI - 项目展示文档

## 项目概述

**项目名称**: Kinlin AI - 基于银河麒麟操作系统的多功能AI交互助手

**项目类型**: 系统多功能交互助手

**开发团队**: Kinlin AI Team

**开发时间**: 2024年

## 一、项目背景

基于银河麒麟操作系统，借助麒麟AI SDK，开发一个功能完善、性能优秀的AI交互助手系统。

## 四、技术架构

### 后端技术栈
- **框架**: Spring Boot 3.2.0
- **数据库**: PostgreSQL 15
- **缓存**: Redis 7
- **认证**: JWT + Spring Security
- **API文档**: Swagger/OpenAPI

### AI服务技术栈
- **框架**: FastAPI 0.104.1
- **异步**: asyncio
- **向量数据库**: ChromaDB
- **文档处理**: easydoc、mineru（可选）

### 前端技术栈
- **框架**: Vue 3 + TypeScript
- **UI库**: Element Plus
- **3D渲染**: Three.js
- **状态管理**: Pinia

### 部署技术
- **容器化**: Docker + Docker Compose
- **反向代理**: Nginx
- **CI/CD**: GitHub Actions
