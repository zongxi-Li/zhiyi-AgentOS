# ACG 引擎可视化面板 — 功能测试样例集

> 入口页面：`/agentos/acg`（ACG 动态群体智能引擎）
> 所有样例均在当前后端真实跑通验证，效果稳定可复现。
> 用法：把「合同文本」粘进输入框，按各样例的「操作」勾选开关，点「启动 ACG 引擎」，对照「预期观察」核对。

---

## 样例 1 · 标准合同审查（展示动态拓扑 + 低熵通信）

**操作**：直接粘贴文本，不勾选任何开关，启动。

**合同文本**：

```
甲方应在货物验收合格后30日内支付全部款项，逾期每日按合同总额万分之五支付违约金；乙方对交付成果享有知识产权，甲方仅获得使用授权；本合同任何争议提交北京仲裁委员会仲裁。
```

**预期观察**：

- **ACG 拓扑图**：呈现多层认知协作网络（约 18 节点 / 17 边），不是一条直线：
  - 6 个**步骤节点**（解析→分类→风险→证据→建议→报告）构成执行主干，由依赖边串联；
  - 每个步骤挂一个**智能体节点**（执行该步的 Agent，execution 边）；
  - 风险/建议/报告等产出结论的步骤挂**记忆节点**（write 边，沉淀阶段结论）；
  - 风险/证据/报告等需依据的步骤挂**证据节点**（support 边，可审计来源）。
  执行完成后，主干步骤节点显示绿色完成态高亮。这张图直观表达了「步骤×智能体×记忆×证据」的思考链条，而非单一流水线。
- **就绪集调度轨迹**：每轮一个就绪节点（线性主干），体现按依赖边推进。
- **低熵通信指标**：平均 Token 节省率约 **22%**，累计节省约 **220+ token**；进度条显示「实际投递」远小于「可获取」。
- **数据血缘**：5 条数据流转记录，如 `contract_parse → clause_classify`，且消费字段只有声明的少数几个（如 clause_classify 只取 contract_type / scope / payment_terms），而非上游全部输出。

**验证点**：这一组证明「引擎按需精准投递、不全盘倾倒」——下游只拿到它声明需要的字段。

## 样例 2 · 风险检测超时 → 自愈恢复

**操作**：粘贴文本，勾选「注入故障演示自愈」，节点选 `risk_detect`，故障类型选「模型超时」，启动。

**合同文本**：同样例 1，或：

```
本服务协议自签署之日起生效，有效期两年；甲方未按约定付款的，乙方有权暂停服务并要求赔偿损失；不可抗力导致无法履约的，双方互不担责。
```

**预期观察**：

- **任务最终状态仍为「已完成」**——故障被自动恢复，无需人工干预。
- **恢复次数**指标显示 **1**。
- **恢复轨迹 tab**：出现两条记录——「故障注入」（risk_detect，故障类型 timeout）→「检查点恢复」（策略 local_replan）。
- 拓扑图中 risk_detect 节点最终仍为完成态（重跑成功）。

**验证点**：这一组证明「接受动态注入的异常，无人工干预下自主完成闭环」——赛题鲁棒性评分项。

## 样例 3 · 启用认知规划器（展示静态优选）

**操作**：粘贴文本，勾选「启用认知规划器」，启动。

**合同文本**：

```
甲方应按月支付服务费，逾期承担违约责任；服务范围包括系统维护与技术支持。
```

**预期观察**：

- 任务完成。规划器先做意图解析，再匹配模板——合同审查类需求会**命中静态模板**（策略 `static_template`），直接复用验证过的流程，零额外规划开销。
- 拓扑图与样例 1 一致（命中模板后升格为同一 ACG）。

**验证点**：这一组证明「静态优选」——已知任务复用高质量模板，而非每次都动态生成。

## 样例 4 · 证据检索为空 → 自愈

**操作**：勾选「注入故障演示自愈」，节点选 `legal_evidence_match`，故障类型选「证据为空」，启动。

**合同文本**：

```
保密条款：乙方应对在合作过程中知悉的甲方商业秘密承担保密义务，保密期限为合同终止后五年；违反保密义务的，应支付违约金人民币五十万元。
```

**预期观察**：

- 任务最终「已完成」，恢复次数 1。
- 恢复轨迹显示 legal_evidence_match 节点的故障注入与检查点恢复。
- 数据血缘记录完整（20+ 条生产/消费事件）。

**验证点**：不同故障类型（证据为空，区别于样例 2 的超时）同样能自愈。

## 样例 5 · 故障节点对比（可选，展示自愈普适性）

逐一把「注入故障」的节点切换为不同步骤，观察都能自愈：

| 节点 | 故障类型 | 预期 |
|---|---|---|
| `contract_parse` | Agent 崩溃 | 完成，恢复 1 次 |
| `clause_classify` | 模型超时 | 完成，恢复 1 次 |
| `report_generate` | Agent 崩溃 | 完成，恢复 1 次 |

**验证点**：自愈机制对任意节点、任意故障类型普适。

## 输入文本素材库（可替换上面任意样例的合同文本）

**采购合同**：

```
甲方向乙方采购服务器设备一批，总价款人民币200万元；乙方应在合同签订后45日内交付并安装调试完毕；验收不合格的，乙方应在10日内免费整改；质保期为验收合格后三年。
```

**劳动合同**：

```
用人单位与劳动者订立无固定期限劳动合同，试用期六个月；月工资标准为税前两万元；劳动者提前三十日书面通知可解除合同；竞业限制期限为离职后两年，单位按月支付补偿金。
```

**租赁合同**：

```
出租方将位于本市的商铺出租给承租方经营使用，租期五年，年租金60万元，每年递增5%；承租方应缴纳两个月租金作为保证金；未经出租方书面同意不得转租。
```

## 排查提示

- 若页面访问被重定向到登录页：先在浏览器登录，或确认路由守卫已放行。
- 若启动后无数据：确认后端 `/ai/core/workflows/runs/{id}/acg` 端点可达（生产经 Java 网关转发到 Python 服务）。
- 故障注入的 `max_triggers` 默认 1，即触发一次后自愈；若想看连续故障导致失败，可在 API 层把 max_triggers 调大（超过单节点自愈上限 3 次会判定失败）。
