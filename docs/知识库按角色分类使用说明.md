# 知识库按角色分类使用说明

## 功能概述

知识库系统现已支持按职业/角色分类存储和管理。每个角色的知识库相互独立，确保不同角色的模型只能访问对应的专业知识。

## 核心特性

### 1. 角色分类存储
- 文档上传时自动分类到当前角色的知识库
- 不同角色的文档完全隔离
- 支持为每个角色维护独立的专业知识库

### 2. 智能检索过滤
- RAG查询时自动过滤，只检索当前角色的知识库
- 确保回答的专业性和准确性
- 避免跨角色知识混淆

### 3. 知识图谱分类
- 知识图谱按角色分类构建
- 可视化时只显示当前角色的知识图谱
- 不同角色的知识图谱相互独立

## 使用方法

### 初始化知识库

1. **运行初始化脚本**（首次使用）：
   ```bash
   cd agent
   python app/scripts/init_knowledge_base.py
   ```
   
   这将导入以下示例文档：
   - `律师-法律知识库.md` → lawyer角色
   - `教师-教育知识库.md` → teacher角色
   - `程序员-技术知识库.md` → programmer角色
   - `作家-文学知识库.md` → writer角色

2. **构建知识图谱**（可选）：
   ```bash
   cd agent
   python app/scripts/build_knowledge_graph.py
   ```
   
   为所有角色构建知识图谱，或指定单个角色：
   ```bash
   python app/scripts/build_knowledge_graph.py --role lawyer
   ```

### 上传文档

1. **选择角色**：在系统中选择对应的角色（如"律师"）
2. **进入知识库页面**：点击侧边栏的"知识库"
3. **上传文档**：
   - 点击"上传"按钮
   - 选择或拖拽文档文件
   - 文档会自动分类到当前角色的知识库

**注意**：
- 文档会自动关联到当前选择的角色
- 如果未选择角色，文档将添加到通用知识库
- 上传时会提示文档将添加到哪个角色的知识库

### 查询知识库

1. **选择角色**：确保已选择对应的角色
2. **进入知识库页面**：点击"知识检索"标签
3. **输入问题**：在查询框中输入问题
4. **获取回答**：系统会从当前角色的知识库中检索相关内容并生成回答

**特点**：
- 自动过滤，只检索当前角色的知识库
- 回答更专业、更准确
- 不会出现跨角色的知识混淆

### 查看知识图谱

1. **选择角色**：确保已选择对应的角色
2. **进入知识库页面**：点击"知识图谱"标签
3. **查看可视化**：
   - 查看实体节点和关系边
   - 使用布局切换按钮切换不同的布局算法
   - 使用搜索框搜索特定实体
   - 点击节点查看详情

**特点**：
- 只显示当前角色的知识图谱
- 切换角色时自动刷新图谱
- 支持多种布局算法（力导向、圆形、网格）

| 作家 | writer | 文学相关知识 |

## 技术实现

### 后端实现

1. **RAGService**：
   - `upload_document()` 方法支持 `role_id` 参数
   - `search()` 方法支持 `role_id` 参数，自动过滤结果
   - 文档存储时包含 `role_id` 字段

2. **RAG API**：
   - `/rag/query` 支持 `role_id` 参数
   - `/rag/documents` 支持 `role_id` 查询参数
   - `/rag/documents` 上传时支持 `role_id` 表单参数

3. **知识图谱服务**：
   - `build_from_documents()` 支持 `role_id` 参数
   - 实体和关系包含 `role_id` 属性
   - `/knowledge-graph/graph-data` 支持 `role_id` 查询参数

### 前端实现

1. **RagQuery组件**：
   - 自动获取当前角色ID
   - 查询时传递角色ID到API

2. **RagView组件**：
   - 文档上传时传递当前角色ID
   - 文档列表按当前角色过滤

3. **KnowledgeGraphVisualization组件**：
   - 获取当前角色ID
   - 只显示当前角色的知识图谱
   - 监听角色变化，自动刷新图谱

## 注意事项

1. **角色选择**：使用知识库功能前，请确保已选择对应的角色
2. **文档分类**：文档会自动分类到当前角色的知识库，无法手动修改

## 常见问题

### Q: 如何为自定义角色添加知识库？
A: 选择自定义角色后，上传的文档会自动分类到该角色的知识库。

### Q: 可以跨角色查询吗？
A: 不可以。系统设计为每个角色只能访问自己的知识库，确保回答的专业性。

### Q: 知识图谱显示为空？
A: 请先运行 `build_knowledge_graph.py` 脚本构建知识图谱，或确保当前角色有已上传的文档。

### Q: 如何查看所有角色的文档？
A: 在文档管理页面，取消选择角色（或选择"全部"），可以查看所有文档。但查询时仍会按当前角色过滤。
