### 立即可用的API

1. **数字人系统**
   ```bash
   POST /ai/digital-human/create
   POST /ai/digital-human/animation
   POST /ai/digital-human/style
   ```

2. **情感感知**
   ```bash
   POST /ai/emotion/analyze
   POST /ai/emotion/response
   ```

3. **角色融合**
   ```bash
   POST /ai/role-fusion/fuse
   POST /ai/role-fusion/weights
   ```

4. **知识图谱**
   ```bash
   POST /ai/knowledge-graph/build
   POST /ai/knowledge-graph/search
   POST /ai/knowledge-graph/reason
   GET  /ai/knowledge-graph/stats
   GET  /ai/knowledge-graph/entity/{entity_id}
   ```

5. **增强的对话和RAG**
   ```bash
   POST /ai/chat/text (支持enable_emotion_aware参数)
   POST /ai/rag/query (支持use_knowledge_graph参数)
   ```
