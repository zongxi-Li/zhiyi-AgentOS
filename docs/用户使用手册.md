## 功能说明

### 1. 文本对话

#### 1.1 开始对话
1. 点击顶部导航栏的"文本对话"
2. 在左侧选择角色（律师、教师、程序员、作家）
3. 在输入框输入消息
4. 点击"发送"或按Enter键发送

#### 1.2 上传文件
1. 点击输入框上方的"上传"按钮
2. 选择要上传的文件（支持图片、文档）
3. 文件上传后会自动附加到消息中

#### 1.3 查看对话历史
- 对话历史自动保存
- 可以滚动查看之前的消息
- 点击"清除历史"可以清除当前对话

#### 1.4 导出对话
1. 在对话界面点击"导出"按钮
2. 选择导出格式（JSON或TXT）
3. 文件会自动下载

### 2. 语音对话

#### 2.1 开始语音对话
1. 点击顶部导航栏的"语音对话"
2. 选择角色
3. 按住麦克风按钮开始录音
4. 松开按钮结束录音
5. 系统会自动识别语音并发送

#### 2.2 播放回复
- AI回复会自动转换为语音播放
- 可以点击播放按钮控制播放

### 3. 角色管理

#### 3.1 查看角色
1. 点击"角色管理"
2. 查看内置角色列表
3. 查看自定义角色列表

#### 3.2 创建自定义角色
1. 点击"创建自定义角色"按钮
2. 填写角色信息：
   - 角色名称
   - 角色描述
   - 系统提示词
   - 对话风格（可选）
   - 性格特点（可选）
3. 点击"创建"保存

#### 3.3 编辑角色
1. 在角色卡片上点击"编辑"
2. 修改角色信息
3. 点击"保存"

#### 3.4 删除角色
1. 在角色卡片上点击"删除"
2. 确认删除

### 4. 系统设置

#### 4.1 通用设置
- **主题**：选择浅色、深色或跟随系统
- **语言**：选择界面语言
- **字体大小**：调整字体大小

#### 4.2 对话设置
- **自动发送**：语音识别后自动发送
- **消息提示音**：收到消息时播放提示音
- **历史记录保留**：设置对话历史保留时间

#### 4.3 数字人设置
- **渲染质量**：选择高、中、低
- **动画流畅度**：调整动画帧率

## 使用指南

### 最佳实践

1. **选择合适的角色**
   - 根据需求选择相应的角色
   - 不同角色有不同的专业领域和对话风格

2. **提供清晰的上下文**
   - 在对话中提供足够的背景信息
   - 使用多轮对话建立上下文

3. **使用文件上传**
   - 可以上传图片、文档等文件
   - AI可以理解文件内容并回答相关问题

4. **导出重要对话**
   - 定期导出重要的对话记录
   - 可以保存为JSON或TXT格式

### 快捷键

- **Enter**: 发送消息
- **Shift + Enter**: 换行

## 常见问题

### Q1: 如何切换角色？
A: 在对话界面左侧选择不同的角色即可。

### Q2: 对话历史会保存多久？
A: 可以在设置中配置历史记录保留时间，默认保留7天。

### Q3: 支持哪些文件格式？
A: 支持图片（jpg, png, gif, webp）和文档（pdf, doc, txt等）。

### Q4: 语音识别不准确怎么办？
A: 确保环境安静，说话清晰，可以重新录音。

### Q5: 如何清除所有对话历史？
A: 在对话界面点击"清除历史"按钮。

### Q6: 系统响应慢怎么办？
A: 检查网络连接，或尝试刷新页面。

### Q7: 如何自定义角色？
A: 在角色管理页面点击"创建自定义角色"，填写相关信息即可。

### Q8: 数字人不显示？
A: 检查浏览器是否支持WebGL，或尝试刷新页面。
