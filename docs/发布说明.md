## 一、系统概述

Kinlin AI是一个基于银河麒麟操作系统的多功能AI交互助手，集成了文本对话、语音对话、数字人、情感感知、知识图谱等创新功能。

## 二、核心功能

### 1. 文本对话
- ✅ 高效准确的自然语言理解
- ✅ 多轮对话上下文管理
- ✅ 对话历史存储和检索

### 2. 语音对话
- ✅ 实时语音识别（WebSocket流式）
- ✅ 高质量语音合成
- ✅ 语音参数调节（速度、音调）
- ✅ 噪音过滤

### 3. 角色管理
- ✅ 4种内置角色（律师、教师、程序员、作家）
- ✅ 自定义角色创建
- ✅ 角色风格学习
- ✅ 角色切换优化

### 4. 创新功能

## 五、安装部署

### 快速开始

1. **克隆项目**
```bash
git clone https://github.com/your-repo/kinlin-ai.git
cd kinlin-ai
```

2. **使用Docker部署（推荐）**
```bash
cd docker
docker-compose -f docker-compose.prod.yml up -d
```

3. **手动部署**
```bash
# 后端
cd backend
mvn clean package
java -jar target/kinlin-ai-backend-1.0.0.jar

# AI服务
cd agent
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000

# 前端
cd frontend
npm install
npm run build
# 部署到Nginx
```

详细部署说明请参考 `README.md`。

## 六、配置说明

### 环境变量
- `KYLIN_AI_API_KEY`: 麒麟AI SDK密钥
- `KYLIN_AI_ENDPOINT`: 麒麟AI服务端点
- `DB_HOST`: 数据库主机
- `DB_PASSWORD`: 数据库密码
- `REDIS_HOST`: Redis主机

### 配置文件
- `backend/src/main/resources/application.yml`: 后端配置
- `agent/app/config.py`: AI服务配置
- `frontend/.env`: 前端环境变量

## 七、API文档

访问 `http://localhost:8080/swagger-ui.html` 查看完整的API文档。

主要API端点：
- `/api/chat/*`: 对话相关
- `/api/voice/*`: 语音相关
- `/api/roles/*`: 角色管理
- `/ai/*`: AI服务接口
- `/performance/*`: 性能监控
