### 3.3 核心算法

#### 3.3.1 联邦平均(FedAvg)

```python
θ_global = Σ (n_i / N) * θ_i
```

其中:
- `θ_global`: 全局模型参数
- `θ_i`: 第i个客户端的参数
- `n_i`: 第i个客户端的数据量
- `N`: 总数据量

#### 3.3.2 差分隐私(ε-DP)

```python
θ_noisy = θ + Noise(0, σ)
σ = sensitivity * sqrt(2 * log(1.25/δ)) / ε
```

其中:
- `ε`: 隐私预算(越小越私密)
- `δ`: 失败概率(通常1e-5)
- `sensitivity`: 敏感度

#### 3.3.3 RAG联邦优化(创新)

```python
# 1. 收集各客户端RAG统计(不含原始文档)
stats = [client_rag_stats_1, client_rag_stats_2, ...]

# 2. 聚合检索模式
global_patterns = aggregate_retrieval_patterns(stats)

# 3. 优化检索参数
optimized_params = {
    'top_k': optimize_top_k(global_patterns),
    'similarity_threshold': optimize_threshold(global_patterns),
    'reranking_strategy': select_best_reranking(global_patterns)
}

# 4. 训练全局语义增强模型
semantic_model = train_semantic_model(global_queries, stats)
```
