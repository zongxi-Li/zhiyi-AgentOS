# ⚠️ 重要：必须清除浏览器缓存

## 当前问题

浏览器缓存了旧的API响应，导致：
- 请求不存在的图片文件（`043838.png`）
- 使用错误的路径（`/api/static/`）
- 实际应该请求（`040415.png`）和使用（`/ai/digital-human/image/`）

## 快速解决方案

### 步骤1：完全清除浏览器数据
```
1. 按 F12 打开开发者工具
2. 点击 Application 标签
3. 左侧找到 Storage
4. 点击 "Clear site data" 按钮
5. 确认清除所有数据
```

### 步骤2：关闭浏览器
```
完全关闭浏览器（不只是关闭标签页）
```

### 步骤3：重新启动
```
1. 重新打开浏览器
2. 访问 http://localhost:5173
3. 按 Ctrl + F5 强制刷新（不是普通F5）
```

### 步骤4：验证
```
1. F12 → Network 标签
2. 勾选 "Disable cache"
3. 查看图片请求：
   ✅ 应该是 /ai/digital-human/image/xxx_040415.png
   ✅ 返回 200 OK
   ❌ 不应该有 043838.png
   ❌ 不应该有 /api/static/
```

## 替代方案：无痕模式测试

```
1. Ctrl + Shift + N（打开无痕窗口）
2. 访问 http://localhost:5173
3. 测试功能
```

## 如果还有问题

检查：
1. 是否真的清除了缓存（看Network标签的请求）
2. 是否强制刷新了页面（Ctrl + F5）
3. 是否完全关闭并重启了浏览器
4. 后端服务是否正常运行

## 开发时最佳实践

```
1. F12 → Network → 勾选 "Disable cache"
2. 每次代码更新后用 Ctrl + F5 刷新
3. 定期清除缓存
```
