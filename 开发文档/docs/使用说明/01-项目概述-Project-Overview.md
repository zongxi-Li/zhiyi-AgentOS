## 1. 项目简介

### 1.1 项目背景

联邦智枢 是一个基于银河麒麟操作系统和麒麟AI SDK开发的系统多功能交互助手。项目旨在为用户提供智能化的文本和语音交互体验，支持多种内置角色和自定义角色功能，能够满足不同场景下的对话需求。

### 1.2 项目定位

联邦智枢 定位为**企业级智能对话助手系统**，主要特点包括：

- **智能化**: 基于大语言模型的自然语言理解和生成
- **多模态**: 支持文本、语音、图像等多种交互方式
- **个性化**: 支持角色定制和个性化对话风格
- **可扩展**: 模块化设计，易于扩展和维护
- **安全可靠**: 基于银河麒麟操作系统，符合国产化要求

### 1.3 核心价值

1. **提升用户体验**: 通过智能对话和个性化服务，提升用户交互体验
2. **降低使用门槛**: 支持自然语言交互，降低技术使用门槛
3. **提高工作效率**: 通过智能助手快速获取信息和完成任务
4. **支持国产化**: 基于银河麒麟操作系统，支持国产化部署

## 2. 项目目标

### 2.1 功能目标

开发一个功能完整、交互流畅的AI助手系统，具备以下核心能力：

- ✅ **高效的文本对话处理**: 支持多轮对话、上下文理解、智能回复
- ✅ **实时语音识别与合成**: 支持语音输入、语音输出、实时识别
- ✅ **多角色智能对话**: 支持内置角色和自定义角色，不同角色有不同对话风格
- ✅ **灵活的角色自定义功能**: 用户可以创建和管理自己的角色
- ✅ **知识库检索增强**: 基于RAG技术的知识检索和增强生成
- ✅ **数字人交互**: AIGC生成数字人形象，实时语音驱动

### 2.2 技术目标

- **高性能**: 响应时间 < 2秒，支持并发用户数 > 100
- **高可用**: 系统可用性 > 99.9%，支持故障自动恢复
- **可扩展**: 支持水平扩展，支持微服务架构
- **安全性**: 支持用户认证、数据加密、内容审核

### 2.3 创新目标

- **智能数字人角色系统**: AIGC生成数字人形象，实时语音驱动
- **情感感知对话**: 多模态情感识别，情感驱动的个性化回复
- **智能角色融合**: 多角色协同，融合不同专业角度的回答
- **知识图谱增强RAG**: 结构化知识检索，支持知识推理
- **联邦学习优化**: 隐私保护的模型持续优化

## 3. 项目架构

### 3.1 整体架构

联邦智枢 采用**前后端分离**的架构设计，主要包含以下三个核心服务：

```
┌─────────────────────────────────────────────────────────┐
│                    用户交互层                            │
│  ┌──────────────┐  ┌──────────────┐                  │
│  │  Web前端      │  │  移动端(规划) │                  │
│  │  (Vue 3)     │  │              │                  │
│  └──────────────┘  └──────────────┘                  │
└─────────────────────────────────────────────────────────┘
                        ↓ HTTP/WebSocket
┌─────────────────────────────────────────────────────────┐
│                    API网关层                              │
│  ┌──────────────┐  ┌──────────────┐                  │
│  │  后端服务     │  │  负载均衡     │                  │
│  │ (Spring Boot)│  │  (Nginx)     │                  │
│  └──────────────┘  └──────────────┘                  │
└─────────────────────────────────────────────────────────┘
                        ↓ REST API
┌─────────────────────────────────────────────────────────┐
│                    AI服务层                               │
│  ┌──────────────┐  ┌──────────────┐                  │
│  │  AI服务       │  │  大模型API   │                  │
│  │  (FastAPI)   │  │  (通义千问)   │                  │
│  └──────────────┘  └──────────────┘                  │
└─────────────────────────────────────────────────────────┘
                        ↓
┌─────────────────────────────────────────────────────────┐
│                   数据存储层                              │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐            │
│  │PostgreSQL│  │  Redis   │  │ChromaDB  │            │
│  │ (关系型) │  │  (缓存)  │  │ (向量库) │            │
│  └──────────┘  └──────────┘  └──────────┘            │
└─────────────────────────────────────────────────────────┘
```

### 3.2 技术栈

#### 前端技术栈
- **框架**: Vue 3.3+ (Composition API)
- **UI组件库**: Element Plus 2.4+
- **状态管理**: Pinia 2.1+
- **路由**: Vue Router 4.2+
- **HTTP客户端**: Axios 1.6+
- **3D渲染**: Three.js 0.158+
- **国际化**: Vue I18n 9.14+
- **构建工具**: Vite 5.0+
- **开发语言**: TypeScript 5.2+

#### 后端技术栈
- **框架**: Spring Boot 3.x
- **ORM**: Spring Data JPA / Hibernate
- **数据库**: PostgreSQL 14+
- **缓存**: Redis 7+
- **安全**: Spring Security + JWT
- **API文档**: Swagger/OpenAPI 3
- **消息队列**: (规划中)
- **开发语言**: Java 17+

#### AI服务技术栈
- **框架**: FastAPI 0.100+
- **异步**: asyncio / aiohttp
- **大模型**: 通义千问 (OpenAI兼容模式)
- **向量数据库**: ChromaDB
- **文档处理**: pdfplumber, python-docx
- **音频处理**: librosa
- **开发语言**: Python 3.8+

#### 基础设施
- **容器化**: Docker + Docker Compose
- **Web服务器**: Nginx
- **操作系统**: 银河麒麟操作系统 (KylinOS)
- **CI/CD**: GitHub Actions (规划中)

### 3.3 系统分层

#### 用户交互层 (UI Layer)
- **功能**: 提供用户界面，处理用户交互
- **技术**: Vue 3 + Element Plus
- **职责**: 
  - 文本输入输出
  - 语音录制播放
  - 角色选择管理
  - 数字人展示

#### 对话处理层 (Chat Layer)
- **功能**: 处理对话逻辑，管理对话上下文
- **技术**: Spring Boot + FastAPI
- **职责**:
  - 文本对话处理
  - 语音对话处理
  - 对话历史管理
  - 上下文维护

#### 角色管理层 (Role Layer)
- **功能**: 管理角色配置和切换
- **技术**: Spring Boot + PostgreSQL
- **职责**:
  - 内置角色管理
  - 自定义角色管理
  - 角色切换优化
  - 角色风格学习

#### AI引擎层 (AI Engine Layer)
- **功能**: 提供AI能力，处理模型调用
- **技术**: FastAPI + 通义千问API
- **职责**:
  - 文本生成
  - 语音识别 (ASR)
  - 语音合成 (TTS)
  - 多模态处理
  - RAG检索增强

## 4. 核心功能模块

### 4.1 文本对话模块

**功能描述**: 实现高效准确的自然语言理解，能够理解用户提出的各类问题，并给出合理、有针对性的回答。

**核心特性**:
- ✅ 自然语言理解：准确理解用户提出的各类问题
- ✅ 智能回答：提供合理、有针对性的回答
- ✅ 多轮对话：支持多轮对话，保持对话的连贯性和逻辑性
- ✅ 上下文理解：根据上下文准确理解用户意图
- ✅ 对话质量评估：自动评估对话质量，提供改进建议

**技术实现**:
- 后端: `ChatService`, `ChatController`
- 前端: `ChatView.vue`, `MessageBubble.vue`
- AI服务: `chat.py`, `aiservice.py`

### 4.2 语音对话模块

**功能描述**: 集成高质量的语音识别和语音合成功能，实现实时语音交互。

**核心特性**:
- ✅ 语音识别 (ASR)：实时准确地将用户语音转换为文本
- ✅ 语音合成 (TTS)：自然流畅的语音合成能力
- ✅ 实时处理：支持实时语音输入和输出
- ✅ 流式识别：支持WebSocket流式语音识别
- ✅ 语音参数调节：支持语速、音调、语音类型调节

**技术实现**:
- 后端: `VoiceService`, `VoiceController`
- 前端: `VoiceChatView.vue`, `VoiceRecorder.vue`
- AI服务: `realtimeasr.py`, `tts.py`

### 4.3 角色管理模块

**功能描述**: 系统内置多种专业角色，用户也可以创建自定义角色。

**核心特性**:
- ✅ 内置角色：律师、教师、程序员、作家等专业角色
- ✅ 自定义角色：用户可以创建和管理自己的角色
- ✅ 角色切换：支持快速切换角色，保持对话上下文
- ✅ 角色风格学习：从对话示例中学习角色风格
- ✅ 角色融合：多角色协同，融合不同专业角度的回答

**技术实现**:
- 后端: `RoleService`, `RoleController`
- 前端: `RoleView.vue`, `RoleCard.vue`
- AI服务: `rolestylelearning.py`, `rolefusion.py`

### 4.4 RAG检索增强模块

**功能描述**: 基于RAG技术的知识检索和增强生成，支持知识库查询。

**核心特性**:
- ✅ 文档处理：支持txt、md、pdf、doc等格式
- ✅ 知识库构建：文档分块、向量化、索引建立
- ✅ 智能检索：向量相似度搜索、关键词匹配
- ✅ 增强生成：检索结果融入AI生成
- ✅ 知识图谱：结构化知识检索，支持知识推理

**技术实现**:
- 后端: `RagService`, `RagController`
- 前端: `RagView.vue`, `RagQuery.vue`
- AI服务: `rag.py`, `ragenhanced.py`, `knowledgegraph.py`

### 4.5 数字人模块

**功能描述**: AIGC生成数字人形象，实时语音驱动，支持多风格切换。

**核心特性**:
- ✅ 数字人生成：调用通义万相API自动生成数字人形象
- ✅ 实时语音驱动：根据语音内容实时驱动数字人口型
- ✅ 表情动作生成：基于情感和音频特征生成表情和手势
- ✅ 多风格切换：支持写实、卡通、二次元三种视觉风格
- ✅ 3D渲染：使用Three.js进行3D模型渲染

**技术实现**:
- 后端: `DigitalHumanService`, `DigitalHumanController`
- 前端: `DigitalHumanChatView.vue`, `DigitalHuman.vue`
- AI服务: `digitalhuman.py`, `imagegenerationservice.py`
