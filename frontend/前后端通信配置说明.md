# 前后端通信配置说明

## 配置概览

### 前端配置

#### 1. API基础配置 (`src/utils/request.ts`)
- **Base URL**: `/api` (通过Vite代理转发到后端)
- **超时时间**: 30000ms (30秒)
- **请求拦截器**: 自动添加JWT Token到请求头
- **响应拦截器**: 统一处理错误和响应格式

#### 2. Vite代理配置 (`vite.config.ts`)
```typescript
proxy: {
  '/api': {
    target: 'http://localhost:8090',  // 后端服务地址
    changeOrigin: true,
    rewrite: (path) => path.replace(/^\/api/, '')
  }
}
```

#### 3. 统一API实例
所有API服务文件现在统一使用 `request.ts` 中的axios实例：
- ✅ `auth.ts` - 认证API
- ✅ `chat.ts` - 对话API
- ✅ `conversation.ts` - 对话历史API
- ✅ `role.ts` - 角色API
- ✅ `rag.ts` - RAG查询API
- ✅ `voice.ts` - 语音API
- ⚠️ 其他API文件（digitalHuman, emotion, knowledgeGraph, roleFusion, search, file）仍需更新

### 后端配置

#### 1. 服务器端口 (`application.yml`)
- **端口**: 8090
- **CORS配置**: 允许以下源访问
  - http://localhost:3000
  - http://localhost:5173
  - http://localhost:5174
  - http://localhost:8080
  - http://localhost:8090

#### 2. CORS配置 (`WebConfig.java`)
- 允许所有HTTP方法: GET, POST, PUT, DELETE, OPTIONS, PATCH
- 允许所有请求头: `*`
- 允许携带凭证: `true`
- 预检请求缓存时间: 3600秒

#### 3. 安全配置 (`SecurityConfig.java`)
- 公开接口: `/health`, `/auth/**`, `/swagger-ui/**`, `/v3/api-docs/**`, `/ws/**`
- 其他接口需要JWT认证

## API响应格式

### 成功响应
后端直接返回数据，HTTP状态码为200：
```json
{
  "token": "xxx",
  "userId": "xxx",
  "username": "xxx",
  "message": "登录成功"
}
```

### 错误响应
后端使用HTTP状态码表示错误：
- **400**: 请求参数错误
- **401**: 未授权（需要登录）
- **403**: 拒绝访问
- **404**: 资源不存在
- **500**: 服务器内部错误

前端会在响应拦截器中统一处理这些错误。

## 常见问题

### 1. CORS错误
**问题**: 浏览器控制台显示CORS错误
**解决**: 
- 检查后端CORS配置是否包含前端地址
- 确认后端端口是否正确（8090）
- 检查请求头是否包含 `Authorization`

### 2. 401未授权错误
**问题**: 请求返回401状态码
**解决**:
- 检查Token是否过期
- 确认Token格式正确: `Bearer <token>`
- 检查后端JWT配置

### 3. 网络错误
**问题**: 请求失败，显示网络错误
**解决**:
- 确认后端服务是否运行（端口8090）
- 检查Vite代理配置是否正确
- 确认防火墙没有阻止连接

### 4. 代理不工作
**问题**: 前端请求无法转发到后端
**解决**:
- 重启Vite开发服务器
- 检查 `vite.config.ts` 中的代理配置
- 确认后端服务地址正确

## 开发建议

1. **统一使用request.ts**: 所有API调用都应该使用 `request.ts` 中的axios实例
2. **错误处理**: 利用响应拦截器统一处理错误，避免在每个API调用中重复处理
3. **Token管理**: Token自动添加到请求头，无需手动处理
4. **类型安全**: 使用TypeScript接口定义请求和响应类型
